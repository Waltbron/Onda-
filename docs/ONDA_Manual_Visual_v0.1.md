# ONDA · Manual Visual Editorial v0.1

**Estado:** criterios aprobados en conversación, sistematización editorial en prueba. **Fecha:** 2026-11-21.

## Norte
Retratar una forma de vivir el Este, no poner monumentos como comodines ni ilustrar literalmente cada evento. La imagen debe mostrar personas y actividades con una geografía creíble, sin falsear lo que se ofrece.

## Estilo y color
Ilustración editorial impresa / serigrafía de textura granulada, contraste claro-oscuro y formas ilustrativas detalladas sin parecer foto filtrada. Paleta orientativa: azul tinta #17253B, coral #F46B60, ocre #E9B66D, marfil #F7F0E4, verde azulado #567F83 y tierra #9D7064. Son referencias, **no códigos de marca aprobados**; prevalece la observación de ilustraciones aprobadas. Conservar variaciones según clima y hora; no convertir todas las escenas en sunsets.

## Composición y casting
1. Una acción principal y contexto natural, sin llenar toda la escena con protagonistas.
2. Alternar vista oblicua, primer plano, plano medio y general, de modo que las imágenes funcionen juntas.
3. Mostrar edades, cuerpos, peinados, expresiones y modos de vestir diversos, inspirados en gente real pero sin copiar fotos de individuos identificables.
4. No todos sonríen a la vez. Mezclar interés, conversación, concentración, descanso y alegría mesurada.
5. Cuando se muestra un sitio reconocible, comprobar fotografía real y perspectiva posible. No agregar faros, puente o Los Dedos donde no se ven.
6. No inventar carteles, logos, escudos o marcas. Para El Popu sigue pendiente símbolo auténtico.

## Mapeo con eventos
Preferir imagen oficial autorizada si se verifica su relación con el evento. En segundo lugar una escena conceptual con misma acción y tipo de espacio; si no coincide, usar recurso gráfico neutro. **No** asociar por categoría o hash si implica una experiencia distinta; un DJ no representa un recital municipal, un teatro no es el Cine MACA y Casapueblo no es cualquier terraza. La ilustración describe una experiencia, no prueba que esa actividad sucedió.

## Uso web
Formato base 4:3, exportación WebP a partir de PNG original sin modificar; usar `object-fit:cover` y zona segura central para etiquetas. En tarjetas móviles revisar recorte de 4:3 y de 16:9 antes de publicación. Ajustar contraste del texto con placas opacas; no sobreimprimir marcas o slogans sobre imágenes con identidad ajena. Conservar PNG maestros sin reemplazarlos.

## Aprobación y flujo
Referencia real -> intención / casting -> generación -> revisión -> aprobación visual -> archivado PNG en Drive -> WebP en GitHub rama de pruebas -> mapeo por etiquetas -> verificación en ONDA Lab -> aprobación para producción. Ningún paso implica por sí solo el siguiente. Registrar fuente, ID, hash, estado y restricciones.
