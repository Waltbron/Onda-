# Bandeja ONDA · Radar secundario

Este directorio contiene el contrato de **hallazgos**, no eventos listos para publicar.

- La tarea de ChatGPT puede encontrar candidatos con datos incompletos, pero debe identificar el enlace original y la hora de revisión. No inventar valores que no estén confirmados.
- Cada candidato debe usar `schema.json` y llevar `verification_status`. Es válido `unverified` mientras se investiga.
- Los hallazgos de agregadores deben enlazarse a una fuente primaria cuando exista.
- Un candidato no modifica `site/data/events.json`, `data/manual.json` ni `data/automatic.json` hasta que pase validaciones y revisión.
- La transferencia automática desde ChatGPT Automations a GitHub o Drive **no está configurada** y debe probarse con autorización antes de asumirla.
- Evitar preferencia personal del fundador en descripciones, puntuaciones o jerarquías públicas de ONDA.
